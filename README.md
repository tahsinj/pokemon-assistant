# STAB Lab

Unofficial desktop team and battle lab for Pokémon Showdown singles. It started
as a helper for the Cobblemon Minecraft mod and is moving to Gen 9 OU and
National Dex OU. The plan is in [docs/SPEC.md](docs/SPEC.md).

Built with Electron, React and TypeScript.

## Features

- Pokédex with forms, learnsets, coverage and threats
- Move index
- Team Builder with set editor, role audit and PC sync
- Battle calculator and Calcdex (damage / KO odds via `@smogon/calc`)
- Live battle tracker with set prediction and move recommendations
- EV / IV planner, breeding odds and spawn lookup
- PC storage with set review
- Counter Draft and Smogon usage viewer

## Getting started

```bash
npm install
npm run dev        # Vite on :5173, then Electron
```

Other scripts:

```bash
npm test           # vitest
npm run build      # renderer -> dist/, electron -> dist-electron/
npm run pack:win   # Windows installer into release/
```

The JSON under `src/renderer/public/data/` is generated by the `fetch-*` /
`parse-spawns` scripts in `package.json` and is checked in, so you don't need
to run them to use the app.

## Cobblemon bridge

`cobblemon-mod/` holds a Fabric mod scaffold that streams battle events to the
app over a local WebSocket (`127.0.0.1:8788`). `npm run mod-mock-client`
replays a scripted battle without Minecraft. See `cobblemon-mod/README.md`.

## Data sources

- Species, learnsets, held items and spawn data: generated from the
  [Cobblemon](https://gitlab.com/cable-mc/cobblemon) mod's data files
- Moves, abilities, items, formes and tiers: [Pokémon Showdown](https://github.com/smogon/pokemon-showdown)
- Damage calculation: [`@smogon/calc`](https://github.com/smogon/damage-calc)
- Usage stats and sample sets: [Smogon](https://www.smogon.com/stats/) and
  [data.pkmn.cc](https://data.pkmn.cc). Only numbers and move lists are
  bundled, no analysis text.
- Sprites: fetched at runtime from [PokeAPI](https://github.com/PokeAPI/sprites)
  and cached locally. No sprite images are included in this repo.

# Pokémon Assistant

Desktop companion for open-world Pokémon games where you catch Pokémon and
build a team. It started as a helper for the Cobblemon Minecraft mod, which is
still the best-supported game.

Built with Electron, React and TypeScript.

## Features

- Pokédex with forms, learnsets, coverage and threats
- Move index
- Team Builder with set editor, role audit and PC sync
- Battle calculator and Calcdex (damage / KO odds via `@smogon/calc`)
- Live battle tracker with set prediction and move recommendations
- EV / IV planner, breeding odds and spawn lookup
- PC storage with set review
- Counter Draft and Smogon usage viewer

## Getting started

```bash
npm install
npm run dev        # Vite on :5173, then Electron
```

Other scripts:

```bash
npm test           # vitest
npm run build      # renderer -> dist/, electron -> dist-electron/
npm run pack:win   # Windows installer into release/
```

The JSON under `src/renderer/public/data/` is generated by the `fetch-*` /
`parse-spawns` scripts in `package.json` and is checked in, so you don't need
to run them to use the app.

## Cobblemon bridge

`cobblemon-mod/` holds a Fabric mod scaffold that streams battle events to the
app over a local WebSocket (`127.0.0.1:8788`). `npm run mod-mock-client`
replays a scripted battle without Minecraft. See `cobblemon-mod/README.md`.
